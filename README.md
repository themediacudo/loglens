# CudoLogLens 업데이트 피드

macOS 앱 [CudoLogLens](https://gitea.cudodev.synology.me:5001/MediaDev/cudologlens)의
Sparkle 인앱 업데이트 피드입니다. 앱이 `appcast.xml`을 읽어 새 버전을 확인합니다.

- `appcast.xml` — 최신 버전 정보 (EdDSA 서명 포함)
- `CudoLogLens-<버전>.dmg` — 배포 파일

이 레포의 파일은 소스 레포의 `publish-update.sh`가 생성·푸시합니다. 직접 편집하지 마세요.
